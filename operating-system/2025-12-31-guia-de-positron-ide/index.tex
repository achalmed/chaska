\subsection{1. ¿Qué es Positron?}\label{quuxe9-es-positron}

\textbf{Positron} es un IDE moderno y extensible para ciencia de datos,
construido sobre \textbf{Code OSS} (el núcleo open-source de VS Code) y
desarrollado por \textbf{Posit Software, PBC} (antes RStudio). A
diferencia de VS Code, trae soporte \textbf{nativo} para Python y R, sin
depender de extensiones externas frágiles.

\textbf{Características principales:}

\begin{itemize}
\tightlist
\item
  Basado en Code OSS → hereda toda la infraestructura de VS Code (paleta
  de comandos, atajos, configuración por \texttt{settings.json},
  extensiones).
\item
  Soporte nativo de Python y R, con consola interactiva (kernel Ark,
  IPython/IRKernel).
\item
  \textbf{Variables Pane}: inspección en vivo de variables del entorno.
\item
  \textbf{Data Explorer}: exploración interactiva de dataframes.
\item
  \textbf{Plots Pane}: historial y exportación de gráficos.
\item
  \textbf{Help Pane}: documentación contextual integrada.
\item
  \textbf{Connections Pane}: gestión de conexiones a bases de datos.
\item
  \textbf{Packages Pane}: gestión visual de paquetes R/Python.
\item
  Soporte nativo de \textbf{Quarto}, incluyendo salida en línea
  (\emph{inline output}) para documentos \texttt{.qmd}.
\item
  \textbf{Posit Assistant}: asistente de IA integrado en el IDE (sucesor
  del antiguo ``Positron Assistant'').
\item
  Galería de extensiones servida desde \textbf{P3M} (Posit Public
  Package Manager), con el mismo catálogo que Open VSX.
\item
  Licencia: \textbf{Elastic License 2.0} (source-available, gratuito
  para uso individual).
\end{itemize}

\textbf{Cuándo usar cada uno:} si tu trabajo combina R y Python (como
flujos con \texttt{reticulate}, Quarto multi-lenguaje, etc.), Positron
es la opción natural. Si tu trabajo es 100 \% R y dependes de funciones

tools de nicho), RStudio sigue siendo una alternativa sólida y bien
mantenida.

\subsection{2. Requisitos previos}\label{requisitos-previos}

Antes de instalar, conviene tener listo lo siguiente (documentación
oficial: \emph{Install Positron}):

\begin{itemize}
\tightlist
\item
  \textbf{Sistema operativo}: Linux (Ubuntu/Debian o RHEL-based), macOS
  o Windows.
\item
  \textbf{Espacio en disco}: \textasciitilde500 MB mínimo para el propio
  IDE.
\item
  \textbf{RAM}: 2 GB mínimo, 4 GB recomendado.
\end{itemize}

\subsubsection{Python}\label{python}

\begin{itemize}
\tightlist
\item
  Positron soporta las versiones \textbf{activamente mantenidas de
  Python, de la 3.9 a la 3.13}.
\item
  Gestores de versiones recomendados: \textbf{uv} (recomendado por
  Posit) o \textbf{pyenv}.
\item
  Positron requiere el \textbf{kernel IPython} (versión 6.19.1 o
  superior) para comunicarse con Python. Por defecto, este kernel viene
  \textbf{integrado (bundled)} con Positron para la implementación
  estándar de CPython.
\item
  Si prefieres control fino sobre tu entorno, puedes desactivar el
  kernel integrado con \texttt{python.useBundledIpykernel:\ false} e
  instalar \texttt{ipykernel} manualmente vía
  \texttt{pip\ install\ ipykernel}.
\end{itemize}

\subsubsection{R (opcional, si lo vas a
usar)}\label{r-opcional-si-lo-vas-a-usar}

\begin{itemize}
\tightlist
\item
  Se requiere \textbf{R 4.2 o superior}. Instálalo siguiendo las
  instrucciones de tu sistema en
  \href{https://cloud.r-project.org/}{cloud.r-project.org}.
\item
  Si quieres manejar múltiples versiones de R en paralelo, la
  herramienta \textbf{\href{https://github.com/r-lib/rig}{rig}} funciona
  muy bien con Positron.
\item
  Si desarrollas paquetes R, conviene tener actualizados estos paquetes
  (mejoran la integración con Positron):
\end{itemize}

\subsection{3. Instalación en Linux}\label{instalaciuxf3n-en-linux}

Positron se distribuye oficialmente como paquete \textbf{\texttt{.deb}}
(Debian/Ubuntu, incluye Kubuntu) y \textbf{\texttt{.rpm}} (Red
Hat/Fedora), para arquitecturas \textbf{x64} y \textbf{arm64}.

\subsubsection{Paso 1 --- Descargar el
instalador}\label{paso-1-descargar-el-instalador}

Descarga el paquete correspondiente a tu arquitectura desde la página
oficial de descargas:

👉 \textbf{https://positron.posit.co/download.html}

Para Kubuntu/Ubuntu (x64), el paquete tiene este formato de nombre:

\begin{verbatim}
Positron-2026.06.0-211-x64.deb
\end{verbatim}

O directamente por terminal:

\subsubsection{Notas importantes para
Linux}\label{notas-importantes-para-linux}

\begin{itemize}
\tightlist
\item
  El instalador \texttt{.deb} \textbf{no se autoactualiza} como en
  macOS/Windows: en Linux, Positron solo \textbf{te notifica} cuando hay
  una actualización disponible; debes descargar e instalar el nuevo
  \texttt{.deb}/\texttt{.rpm} manualmente.
\item
  Existe un detalle conocido y ya corregido en versiones recientes:
  versiones antiguas del desinstalador \texttt{.deb} podían eliminar por
  error las fuentes APT y la llave de firma de VS Code si lo tenías
  instalado también. Esto está solucionado desde el changelog de
  2026.06.0.
\end{itemize}
